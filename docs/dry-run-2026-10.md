# Dry run before the first live event (ליגת העל בהובלה, 28-29.10.26)

Goal: run one throwaway lead competition end to end on the live apps, with real phones, before the
event, and leave nothing behind. Target date: **by Sunday 25.10.26** (time to fix what breaks).

People: the admin (staff app on a laptop), 2 judges with their own phones (one new judge invited for
the test), 1 person on the public viewer (phone), optionally one more phone as the "big screen".

## Setup (Claude, from the terminal, with the admin's OK)

- A competition **"ניסיון – ליגת העל בהובלה (יימחק)"**, series `other`, no season (never counts for the
  rankings), today's date, status draft.
- 12 test climbers ("ניסיון 1" … "ניסיון 12", 6 men, 6 women) as new profiles; their ids are listed so
  they are deleted by id afterwards.
- Categories גברים / נשים. Everything else is done in the app by the admin (that is what is tested).

## Run (the admin and the judges, in the apps)

| # | Step | Who | Passes when |
|---|---|---|---|
| 1 | Import the 12 climbers from a roster CSV into the two categories, with bibs | admin | all 12 registered, bibs shown |
| 2 | Qualification round: 2 routes per category | admin | round shows the start list |
| 3 | Invite the new judge by share link (WhatsApp); judge sets a password | admin + judge | judge signs in, has the judge role |
| 4 | Assign judge A to route 1, judge B to route 2 | admin | each judge sees only their route |
| 5 | Publish, set the round live | admin | viewer shows "בשידור חי"; home page shows the live card |
| 6 | Score every climber: holds, +, top, "on the wall" | judges | viewer updates within ~5 s; "on the wall" shows the right climber |
| 7 | Two judges open the same climber | judges | the second sees "בשיפוט אצל …" and moves on |
| 8 | Weak signal: one judge turns on airplane mode for one save, then off | judge | today: "השמירה נכשלה", then saving again works (the offline queue is not built yet) |
| 9 | Correct a locked result, unlock one, check the change log | admin | log names who changed what |
| 10 | Open and close an appeal | admin | "ערעור" tag shows and clears on the viewer |
| 11 | Close qualification, generate the final start list (top 8; make a tie at 8th) | admin | the tie advances both; seeds kept |
| 12 | Final: 1 route, with times | judges | ties in the final break on time |
| 13 | PDF of the results | admin | prints in Hebrew, right to left |
| 14 | Mark finished | admin | home page shows the winners; climber pages show the result |
| 15 | Fallback check: open the temporary app and the mirror script once | admin + Claude | mirror prints its SQL (not applied) |

Write down every problem with the time, the phone and the screen (a screenshot is enough).

## Cleanup (Claude, with the admin's OK)

Delete by explicit ids: the test competition (its categories, rounds, registrations, results and audit
rows), the 12 test profiles, and the test judge's account if not needed. Check the rankings and home
page afterwards: no trace of the test.

## Before the event (after the dry run)

- Fix what broke; the judge-pad offline queue (option B, decided 2026-10-17) if it can be done and tested
  in time, otherwise judges know to re-tap on "השמירה נכשלה".
- Enter the real competition: categories (incl. U17 if it runs inside the event), roster CSV, rounds,
  judges and assignments; publish the day before.
- Event morning: every judge signs in once on the venue wifi/cellular; the admin keeps the temporary app
  ready as the fallback.
